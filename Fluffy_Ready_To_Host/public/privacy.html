Privacy Policy

Last updated: July 2026

🔍 What We Collect

  • Username — chosen by you at registration.
  • Email — only if you use Gmail OTP verification (optional).
  • Password — stored as plain text in local JSON (this is a local/indie server — use a unique password).
  • Game data — bones, completed levels, skin, bio, friends list.
  • Chat messages — stored up to the last 80 messages (public).
  • Mailbox messages — stored server-side, visible only to sender and recipient.

📧 Email Usage OTP only

Your email is used only to send your one-time login code (OTP). We do not send marketing emails, share your email with third parties, or store it beyond your user profile.

✅ Email verification is completely optional. You can play without providing an email using username + password.

🔒 Data Storage

All data is stored locally on the server in JSON files:

  • data/users.json — user accounts
  • data/levels.json — community levels
  • data/chat.json — recent chat (last 80 msgs)
  • data/mail.json — mailbox messages
  • data/friends.json — friend connections
  • data/updates.json — owner announcements

This is a personal/indie game server. Data is not backed up automatically — treat it as best-effort storage.

👁️ Data Visibility

  • Public: username, role, bones, bio, completed level count, friend count
  • Private: email, password, mailbox contents, exact friend list
  • Owner-visible: all user data (for moderation purposes)

🗑️ Deletion

To delete your account and all associated data, contact the owner at sonuubhagat11@gmail.com or via the in-game Mailbox. We will process the request within 7 days.

🔄 Changes

We may update this Privacy Policy. Changes will be announced via the in-game Updates feed. Continued use of the platform constitutes acceptance.
