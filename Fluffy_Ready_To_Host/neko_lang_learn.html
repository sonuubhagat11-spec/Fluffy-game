NekoLang Learning App

Lesson 1: Basics

NekoLang is a Python-like language designed for beginners to make games easily.

To print text, use the print command:

print Hello World

Lesson 2: Game Features

You can easily load 3D models and trigger anime effects.

Load a model:

load_model player.glb

Trigger an effect:

anime_effect speed_lines

Lesson 3: Variables

Set variables using the equals sign:

score = 100
print score

Try it out in the NekoLang IDE!
